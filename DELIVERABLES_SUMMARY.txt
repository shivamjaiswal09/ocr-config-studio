🚀 USAGE FLOW
═══════════════════════════════════════════════════════════════════════════════

Step 1: Admin creates template via UI
        ↓
Step 2: Admin publishes template
        ↓
Step 3: Client sends POST /api/ocr/extract with document
        ↓
Step 4: System resolves template (client+branch+transporter+doc_type)
        ↓
Step 5: System builds instruction payload
        ↓
Step 6: System calls OpenAI Vision API
        ↓
Step 7: System normalizes response
        ↓
Step 8: System validates fields
        ↓
Step 9: System stores audit record
        ↓
Step 10: Client receives canonical JSON
